# AI 相机交互原型

默认入口：`index.html` → 评审讲解台。点击“打开对应原型”体验各阶段。

- 完整体验：`应用启动页_v0.1.html`
- 产品首页：`1.0.0一级页面框架_v0.4.html?tab=discover`
- 照片与视频、任务、授权、反馈均为交互演示，没有连接真实生成或邮件服务。
- 演示任务与编辑缓存保存在当前浏览器，不会跨设备共享。
- 请通过 GitHub Pages 或本地 HTTP 服务打开，以支持编辑缓存和多页跳转。

## GitHub Pages

在仓库 Settings → Pages，选择 Deploy from a branch，分支 main，目录 / (root)，保存。
